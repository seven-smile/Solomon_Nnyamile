What This Is

This was an academic project in the early stages of my development journey - I'll say that upfront, because I think honesty about context matters. But "academic" doesn't mean "toy." The goal was to build a functioning e-commerce platform for digital products - apps, software, e-books - with the full feature set you'd expect from a real product: user authentication, product catalogue, search and filtering, shopping cart, checkout, order tracking, wishlist, and product reviews.

I built this with one collaborator, Prince Jan. It's live on GitHub Pages.

What I Built

The frontend was built in React - component-based, with state management handling the cart, wishlist, and user session across the application. The backend runs on Node.js and Express, with a MySQL database handling product data, user accounts, and order records.

What I'd Do Differently

If I were building this today rather than as a student, the architecture would look different. I'd think harder about separating concerns on the backend - the Express app does too many things in too few files. I'd add proper error boundaries on the React side. And I'd invest more in the mobile experience; the responsive design works, but it was an afterthought rather than a starting point.

I'm including this project on my portfolio not to pretend it's production software, but because it's honest evidence of where I was technically - and a fair comparison point against where I am now. Every senior developer has a version of this project in their past.
